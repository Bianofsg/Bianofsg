## 🚀 Projeto principal

### 🔐 AutWebQR — Autenticador por QR Code + Biometria

Desenvolvido por necessidade real: substituir leitores biométricos físicos de alto custo
por uma solução usando o smartphone do próprio usuário. Nasceu dentro de um sistema
de controle de ponto e evoluiu em 3 versões ao longo do tempo.

| Versão | Tecnologia | Repositório |
|--------|-----------|-------------|
| v1 | HTTP + cookie | [autwebqr-cookie](https://github.com/Bianofsg/autwebqr-cookie) |
| v2 | HTTPS local + WebAuthn + biometria | [autwebqr-local](https://github.com/Bianofsg/autwebqr-local) |
| v3 | VPS + Let's Encrypt + geolocalização | [autwebqr-server](https://github.com/Bianofsg/autwebqr-server) |

O sistema de ponto que originou o projeto:
👉 [sisponto-qrauth](https://github.com/Bianofsg/sisponto-qrauth)
